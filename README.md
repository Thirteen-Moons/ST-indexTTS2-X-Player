# ST-IndexTTS2-X-player🎙️

  
为SillyTavern设计的文本转语音（TTS）扩展。

基于原始插件 [indexTTS player](https://github.com/bronie-honkai/st-indextts2) 的二次修改 [st-indextts2-plus](https://github.com/xiaoxiongweihu/st-indextts2-plus)，再次进行开发与优化，让你的SillyTavern语音体验更加流畅。

版本：1.2.6 | 作者：Thirteen-Moons

<br>

> *不会再在DC通知更新，有问题请到 git 提 issue，请关注插件是否有更新提醒（红字new，而非酒馆下载按钮，酒馆更新检查有问题）。*
> 许多常见问题已在更新中解决，详见更新日志，还有其他问题可查看常见QA。

## 💡适用人群

  - 想使用本地语音模型，且电脑显存达8G。

  - 此插件不限于PC或手机端SillyTavern，仅是语音模型后端需在电脑上运行，前端面板仅填入API即可使用。

## 🎁 功能特色

### 🎤 多角色智能配音

  - 为每个角色单独配置音频，自动匹配朗读
  - 快速管理与切换角色配音
    <br><br>


### 📚 灵活的文本解析模式

  - 听书模式：全文朗读，但会过滤掉所有不应被朗读出的符号
  - RP模式：仅朗读引号内对话
  - GAL模式：支持单卡多角色分别配音、场景音效，仅朗读带格式标签的台词
<br><br>
  
### ⚡实时自动流式播放

  - 智能分段：智能切割文本，让推理无需等待
  - 自动播放：收到回复后自动生成语音并播放
<br><br>
  
### 💓 情感向量

  - 支持 【**49**】 种情感向量，生成更富有情感的语音
<br><br>
  
### 🖱️ 悬浮播放器

  - 播放/暂停控制
  - 进度条拖拽
  - 音量与速度控制
  - 可选隐藏
<br><br>
  
### 🏠 场景配音

  - 为不同场景分别配置背景音
  - 自动播放
  - 可选循环播放
<br><br>
  
### 💻 多预设管理

   - 支持保存与切换多套配音方案
<br><br>
  
### 💾 音频缓存

  - 本地音频缓存，已生成的语音无需重复推理即可随时播放
  - 支持导入/导出、清空音频缓存
<br><br>

  - 修复悬浮播放器在移动端不显示的bug。
  - 大幅简化代码，运行与推理更流畅。
 <br><br>

   - **正则过滤**：
     > - 未勾选自定义正则过滤时，采用代码内的硬过滤，即便是复杂的MD、json等文本，均能过滤干净（少量emoji除外），仅朗读正常的对话部分。
     > - 可选自定义正则：勾选启用正则过滤时，仅使用填入的正则。
     
<br>

   - **49种情绪**：将情绪映射由默认8种增加到49种。(请使用此说明中的示例提示词，而非插件默认自带）
<br>

  - **实时伪流式分段**：
      新增分段逻辑，将需要朗读的长文本过滤后再进行切割，每推理完一句立即播放，并同时推理下一句，达到更佳的实时输出的效果。

<br>

  - **RP解析模式**：适用于常见小说体RP，仅读引号内，支持中、英、直角引号。
    > * 可选功能：延迟播放。可根据阅读速度设置延迟。
<br>
          
  - **真群聊配音**：在st的真群聊中（即多个角色卡组合成一群聊），无需启用提示词注入，即可为每个角色绑定不同的音色。三种解析模式均支持。
<br>
  
  - **单人模式**：在单角色的情况下进行音色绑定，无需额外启用提示词注入。三种解析模式均支持。
<br>

  - **GAL模式格式兼容**：格式兼容性增强。现对话内容的包裹符号，支持中、英、直角三种引号，与无引号。
    > * 可选功能：延迟播放。可根据阅读速度设置延迟。
<br>
  
  - **隐藏播放器**：可选隐藏悬浮播放器。
<br>

## 📖 使用说明

### 📦 安装指南

1. 将本仓库克隆或下载到 SillyTavern 的扩展目录：

   ```
   https://github.com/Thirteen-Moons/ST-indexTTS2-X-Player.git
   ```

2. 下载Index-tts-2.0 整合包：
   ```
   https://tcnlo9s668u9.feishu.cn/wiki/KRQ9wuqiViSOmJkfHxacNFfknjh
   ```

3. 使用本仓库中的 **api.py** ，覆盖掉后端目录下的api.py，路径project\IndexTTS\nvidia\api
4. 启动 IndexTTS2 后端语音模型服务 api.bat，路径project/IndexTTS/nvidia/api.bat
   > * 注意：推理与输出速度取决于个人显卡性能，显卡越强，速度越快。

5. 在 SillyTavern 扩展面板中启用 **IndexTTS2 Player**
   <br><br>
  ---
### 🚀 快速配置
<br>

1. API地址：保持默认即可。若需使用情感向量，则将 *TTS服务地址* 改为 `http://127.0.0.1:7880/api/v1/tts/tasks`
    > * 若PC端播放正常，但手机局域网播放报错，或不出声，则将三个地址的 127.0.0.1 改为本地ipv4地址。
<br>

2. 在后端语音模型服务的文件夹中，添加参考音频。
   > * 角色参考音频文件放置于后端 ***api/ckyp/*** 目录（若无则自行新建）。
   > * 场景音频文件放置于后端 ***api/pjy/*** 目录（无则新建），文件名需与标签名一致。
   > * 注意：参考音频的长度最好在10-20秒内，包含陈述句、语气词、问句、笑声的音频效果会更佳。实际语音效果与音质，取决于参考音频质量。
<br>
  
3. 点击待对话的 AI 消息旁的 ⚙ 按钮，打开配音配置面板。输入角色姓名并保存，下拉选择需要使用的声音，绑定。
<br>
  
4. 在插件设置面板中，选择需要的解析模式。听书模式、RP模式、GAL模式选一。  
<br>
  
5. 勾选「回复后自动推理」和「推完N句后自动续播」，推理句数推荐设为 1。
<br>
  
6. 开始聊天。
         <br>

## 🎵 文本解析模式说明


### ✅ 听书模式

  全文朗读，会过滤掉所有不应朗读出的符号与内容。如MD符号、代码块、链接、斜体内容、星号、xml标签等。

  **适合听故事、人机对话、常见的括号体RP对话。** 能处理AI实际输出的代码等乱七八糟的内容，但不适合用了许多```仅影响显示的正则美化```过于复杂的前端卡。
  
  推荐设置：<br>勾选```回复后自动推理```，```推理完N句后自动续播```，```推理句数设为1```。此设置可达到AI回复完就开始流式播放的效果。<br>
    推荐不勾选```启用正则过滤```，交给脚本处理（针对听书模式内置的过滤比用户自定义正则会处理的更干净）。
   <br><br><br>
**解析效果**
```
【原文一】：
### 问题诊断：为什么移动端不显示
你的临时测试代码能工作，说明基础显示逻辑（display、opacity、z-index）没问题。问题出在**正式CSS中的特定属性组合在移动端被错误解析**。
  
【实际朗读】：
问题诊断：为什么移动端不显示
你的临时测试代码能工作，说明基础显示逻辑没问题。问题出在正式CSS中的特定属性组合在移动端被错误解析。

  
【原文二】：
（攥紧了拳头，指节因用力而微微发白）我…不是这个意思。（声音因痛苦而颤抖着）
  
【实际朗读】：
我…不是这个意思。


【原文三】：
*攥紧了拳头，指节因用力而微微发白* 我…不是这个意思。*声音因痛苦而颤抖着*

【实际朗读】：

  （注：逗号句号省略号等正常符号均不会被朗读出）

### ✅RP模式

  只朗读引号内，支持中、英、直角三种引号，**适合常见的小说体RP对话** 。不适合世界书/预设让AI**直接在消息中输出了各种代码**的角色卡，但使用正则美化```仅影响表层显示```基本不受影响。（与听书模式相反）

  **推荐设置**：<br>
  - 自动播放：勾选```回复后自动推理```，```推理完N句后自动续播```，```推理句数```设为1，```延迟播放下一句```（根据AI输出的大致篇幅，自身阅读速度来决定）。<br>
  - 手动播放：勾选```回复后自动推理```，不勾选```推理完N句后续播```或```推理完毕后自动续播```,手动使用```播放整层楼```消息右上角小喇叭，延迟播放可选<br>
  - 可选```启用正则过滤```，根据自身情况处理需过滤掉的内容。

  <br><br>
**解析效果**

```
【原文】：
夜风掠过废弃的站台，铁轨上长满了枯黄的杂草。阿哲把背包甩到肩上，抬头看向站台尽头模糊的信号灯。
“火车应该还有十分钟进站。”他看了看表，声音压得很低。
站台角落的路人一边皱着眉头翻动手中的旧地图，一边打量着这个年轻人。此时远处传来低沉的汽笛声，划破了雨夜的寂静。
   
【实际朗读】：
火车应该还有十分钟进站。

### ✅GAL模式

  **唯一支持单卡多角色分别配音、情感向量、场景音的模式**，但需开启提示词注入。
  <br>
  
  推荐设置：
  - 自动播放：回复后自动推理，推理完N句后自动续播，推理句数设为1，延迟播放下一句（根据自身阅读速度调整），同场景下循环播放场景音，淡入淡出0.2
  - 手动播放：启用行内增强渲染，回复后自动推理，自行点击行内消息进行播放，同场景下循环播放场景音，淡入淡出0.1

## ❔常见Q&A

Q：为什么什么也无法播放，后台直接报错？
> A：请确保已经替换了py文件，并且启动的是api.bat。
<br>

Q：如何远程用移动端使用？
> A：在同一个局域网时，地址填的是本地ipv4就可用移动端使用，但是音频文件需先在电脑上配置好，因为手机用浏览器连接电脑局域网时，无法直接打开电脑磁盘中的文件夹。
而想要外出远程使用，需要内网穿透，如何内网穿透请自行功课。
<br>

Q：支持多语言吗？
> A：插件本身界面没做多语言，而**TTS播放的语言，AI输出什么语言播的就是什么**。但现有听书模式中的自动分段逻辑是针对中文的，若使用其他语言，断句可能会有点怪。其他模式不受影响。
<br>

Q：为什么RP模式/听书模式会播放出代码/其他内容？
> A：在听书模式下，捕捉的是渲染后的文本，如果启用了太多”仅作用于显示“的美化正则，可能会把一部分该过滤掉的内容念出。**现插件已经针对常见的美化正则进行了匹配，不会被念出（如状态栏）。若再进行严格匹配，可能会误伤正文**。<br>
因此，若使用听书模式，请不要使用有过多正则美化（如整个消息正文都在美化代码/气泡中）的角色卡。同时，听书模式请**勿**勾选 启用正则过滤。
<br>

> 在RP模式下，捕捉的是原始消息，仅影响显示的正则美化不会影响到播放（本来就不会念出来，即便其中包括引号文本），**但如果某些预设/世界书要求AI直接输出含代码的文本，若其中还含有引号内容**，则引号内容会被播放出。<br>
**现版本已经针对常见标签进行了处理，不会再被念出**。但每个人使用的角色卡不同，无法兼顾到所有人的细微情况。**可勾选 启用正则过滤，根据自身情况使用正则匹配过滤**。
<br>

Q：为什么听书/RP模式会念出思维链中的部分内容？
> A：如果念出思维链中的内容，代表不是模型原生的思维链，而**是你使用的预设强行要求模型额外输出的思维链**。<br>
针对这类思维链，已对常见的标签进行了匹配```think、thinking、thought、details、summary```，用以上这些名称命名的xml标签中的内容不会再被念出。若你的思维链不是以这些标签进行包裹，则可通过更改预设中要求AI输出的标签名来解决。
<br>

Q：为什么听书/RP模式会念出其他插件让AI输出的部分非正文内容？
> A：脚本能匹配的是格式与符号，不同插件输出的内容都不同，虽然代码内已经对常见的标签、思考块、状态栏等都进行了匹配过滤，但过于个性化的情况个人无法进行预知。<br>
若使用的插件过多，且它们都有让AI输出内容到消息中，可使用GAL模式，在此模式下，不符合对话格式的内容均不会被念出。
<br>

Q：感觉角色情绪平淡/用力过猛。
> A：现有的情感映射强度，是用了四个不同音频（两个情感丰富、两个略平淡）调出来的适中值，若再进行改变，可能会导致由于参考音频本身的情绪浓度不同，而效果不佳，**现有数值能适应大多情况**。
若本身使用的参考音频本身全都偏平淡，可将代码中的映射数值适量调高；而若用的所有参考音频都情感丰富，播放效果略用力过猛，则可尝试将数值调低。
<br>

Q：场景音播放速度略慢。
> A：在一次对话中，若是初次播放某场景音，会有几秒加载延迟，略慢于人声，这是预期内行为。而当某场景音已经被播放过，后续的消息若再出现此场景音，则速度会提升，与人声齐平同出。
<br>

Q：indexTTS2出2.5了，会做对应更新吗？
> A：2.5模型相较于2没有大的改变，现模型更新换代极快，每个版本都追会非常疲惫，若出3.0版本，且有非常大的改进，才考虑做支持。同理qwen3这类模型。
<br><br>

## ❓如何获取自己想要的音频

1. 打开含有你喜欢的某角色的游戏/其他资源。

2. 关闭背景音效，选取一段角色台词，最好清晰无回声与杂音，包括长陈述句、短问句，语气词、笑声（台词内容最好连贯，而非每句都毫无关联）。

3. 用电脑/移动设备开始录屏（务必关闭麦克风），播放角色台词，录制。

4. 将录制好的mp4文件剪辑（如剪映）至10-20秒内，保存文件。

5. 上传至电脑，复制文件作为备份，以免后续需重新剪辑，文件却损坏了。

6. 将备份文件的后缀直接改为mp3/wav等音频格式，并重命名为你喜欢的名字，保存。

7. 将完成的音频放置参考音频ckyp目录。

场景音同样可参考上述操作。
<br>

### ❗注意：
参考音频的质量至关重要，假设参考音频本身就是“傲娇”腔调，那么即便不用GAL模式，不使用格式注入情绪标签，语音本身也会带有傲娇腔。
反之，若参考音频本身是机器播音腔，即便使用情绪标签，也难以生成自然的效果。

同一个情绪标签，作用于本身语气自然丰富、拥有情感的参考音频上，与作用于死板的音频上，效果会差异巨大。
